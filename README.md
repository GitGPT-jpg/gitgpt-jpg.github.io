# 张腾 · 个人主页

单文件静态页，没有构建步骤，没有外部依赖和外部请求。

## 预览

双击 `index.html`，或者：

```sh
python3 -m http.server 8765    # 然后打开 http://127.0.0.1:8765/
```

## 测试

```sh
node --test tests/
```

测试直接取 `index.html` 里 `<script id="zt-sim">` 这一段来跑，页面用的和测的是同一份代码。

## 结构

- `index.html`：页面、样式、脚本都在这里。
  - `zt-sim`：时间线模型、BiDi 分配、实验记录判定。不碰 DOM。
  - 第二段脚本：粒子光路（两层 canvas）和各处交互。
- `tests/sim.test.mjs`：时间线模型的测试。
- `drafts/`：早先一版“北辰演练”的引擎和它的测试，没有接入首页。

## 说明

- 推理时间线是原理示意，数值在 `zt-sim` 的 `CFG` 里，不是实测。
- 规划表、拓扑图和实验记录都是抽象示意。
- 字体用系统字体栈，不加载网络字体。
