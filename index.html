01 · INFERENCE TIMELINE

时间到底花在哪一步？

刚才那条光路，现在是下面这根时间轴。发一个请求，看它依次经过排队、Prefill，直到首个 token 到达，再一个 token 一个 token 地把话说完。

前缀系统提示和排障手册，640 tokens 问题“时间到底花在哪一步？”，160 tokens

点「发送请求」。两次请求会上下对齐画在同一根时间轴上。

原理示意：数值是为了说明原理设定的，不是实测；回放放慢了 3 倍。两次是同一个请求、同样的排队；没命中的部分照常计算，缓存查找的开销忽略不计。
